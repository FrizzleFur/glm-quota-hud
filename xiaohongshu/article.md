## 正文

姐妹们兄弟们，用 Claude Code + GLM Coding Plan 的朋友一定懂这种痛👇

套餐有 5 小时窗口、周积分池、月池……
到底还剩多少额度？窗口几点重置？
切到另一个账号，结果 5h 窗口早用完了😱

我受不了了，写了个开源小工具：glm-quota-hud

【效果直接看图2】
状态栏里 GLM 额度直接变成彩色进度条：
V1 5h ██░░░ 1%-3:55 · V3 5h ██░░░ 40%-3:56 周29%-4d

✨ 三个杀手锏：

1️⃣ 用量分档变色
低于70%是绿色（安心）
70-85%变黄（注意）
85%以上变红（快满了！）
Catppuccin Mocha 配色，和我的终端主题一套色系

2️⃣ 双账号同屏
5h窗口套餐 + 积分套餐并行探测
120秒缓存，API 零压力

3️⃣ 配合 CC Switch 用（这个最爽）
切账号前跑一条命令，所有账号的窗口余量一屏看清
再也不用"切过去才发现没额度"了

【图3是 CLI 直读模式】

🔧 安装只要3步（图4教程）：
git clone → bash install.sh → 配 token
零依赖纯 Python，单文件
